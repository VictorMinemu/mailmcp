# MailMCP Implementation Plan

**Goal:** Publish a usable, tested foundation for secure local and hosted MCP email management.

**Architecture:** Shared account/mail services used by local stdio MCP, hosted OAuth HTTP MCP and the session-protected web API. Encrypted disk state; ephemeral hashed browser tokens.

**Tech Stack:** Node.js >=22.17.0, TypeScript, official MCP SDK, Zod, ImapFlow, Nodemailer, Mailparser; native HTTP/TLS/crypto.

**Spec:** [Design](../specs/2026-09-14-mailmcp-design.md)

## Global constraints

TLS verification is mandatory. Credentials never return in account responses. Local mode binds to 127.0.0.1. Hosted mode uses a configured HTTPS origin, OAuth/OIDC and per-user ownership. Invitations are a separate milestone; mailbox provisioning is outside scope. Only operator-allowlisted mail hosts can be contacted.
